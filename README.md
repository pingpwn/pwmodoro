# pwmodoro
![pomodoro](tomato.png)

A minimal pomodoro timer written in 100 lines of pure C!


### Setup
+ Install Gtk3.0 following the [instructions](https://www.gtk.org/docs/installations/linux/), according to your distro.
+ Clone the repository: `git clone https://github.com/pingpwn/pwmodoro` 
+ Inside the ./pwmodoro directory, run `make`
### Usage
+ Run `./pwmodoro`
+ You can run `./pwmodoro {minutes}` to specify the minutes of study, the default is 25
+ The break is 5 minutes
